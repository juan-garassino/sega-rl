# RL-sega-rl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Train PPO agents on Street Fighter II' SCE and Sonic 1 (Sega Genesis, stable-retro) on RunPod, with live training-health monitoring that stops broken runs and removes the pod.

**Architecture:** One uv package `sega_rl` with a shared retro wrapper and per-game adapters (`sf`, `sonic`, `airstriker`), an SB3 PPO trainer wired to a `HealthCallback`, eval/video callback and MLflow, and an archetype-B RunPod image launched and kept authenticated by GitHub Actions (WIF), copied from `005-products/007-deep-sculpt`.

**Tech Stack:** Python 3.12, uv, stable-retro, gymnasium, stable-baselines3 ≥2.4, torch (cpu extra locally / cu126 extra in image), opencv-python-headless, optuna, mlflow-skinny, imageio[ffmpeg], tensorboard, pytest; Docker (nvidia/cuda:12.8.0-devel-ubuntu22.04), GitHub Actions, RunPod GraphQL, GCS.

**Spec:** `docs/superpowers/specs/2026-11-24-sega-rl-design.md` (read it; this plan argues from it).

## Global Constraints

- Python 3.12, uv only (`pyproject.toml` + `uv.lock`, hatchling, `src/` layout); no `requirements.txt`, no pyenv.
- `from __future__ import annotations` in every module; stdlib `logging.getLogger(__name__)`, no `print` outside CLI output.
- CLI: `argparse` only, subparsers `dest="cmd", required=True`, one `_cmd_<verb>(args)` each.
- Config: `pydantic-settings` `Settings` with `env_prefix="SEGARL_"`, `extra="ignore"`, each field inline-commented with its env var + example; module singleton `settings = Settings()`.
- Tests: pytest, flat `tests/`, stub classes not `Mock`; `pythonpath=["src"]`, `testpaths=["tests"]`.
- **stable-retro allows only one emulator per process**: tests and code that need more than one env must use `SubprocVecEnv` or close the previous env first.
- ROMs never in git or the image: `roms/` gitignored; pod pulls from `gs://garassino-ml-artifacts/sega-rl/roms/`.
- Integrations: `StreetFighterIISpecialChampionEdition-Genesis-v0` (state `Champion.Level1.RyuVsGuile`), `SonicTheHedgehog-Genesis-v0` (state `GreenHillZone.Act1`), `Airstriker-Genesis-v0` (bundled).
- Artifacts: `gs://garassino-ml-artifacts/sega-rl/runs/<RUN_ID>/{checkpoints/,best_model.zip,videos/,tb/,health.json,config.json,DONE}`.
- MLflow: experiment `sega-rl`, run name `<GAME>-<RUN_ID>`, only when `MLFLOW_TRACKING_URI` is set; a tracker error never fails training.
- No service-account JSON keys anywhere; GCS auth = short-lived token from WIF, refreshed every 50 min.
- Local machine: one heavy job at a time; local training only via `make smoke` (`nice -n 19`, 2 envs, ≤2k steps). Never `docker build` locally.
- Commits: Conventional Commits, scope `sega-rl`, trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Work on branch `feat/trainer`; `main` gets only the initial commit until the PR merges.

## Review Focus

1. **ROM missing or wrong hash on the pod** → entrypoint logs a clear error, writes `health.json` status `CRITICAL` reason `rom`, and removes the pod (no idle billing). Test: Task 9 `test_entrypoint_rom_missing_terminates`.
2. **Container restarts** → with `DONE` in GCS it exits and removes the pod; without it, training resumes from the newest checkpoint with the same `num_timesteps`. Tests: Task 8 `test_resume_continues_timesteps`, Task 9 `test_entrypoint_done_marker_exits`.
3. **Emulator subprocess dies or hangs** → FPS-zero rule fires CRITICAL within 5 min; SubprocVecEnv `EOFError` is caught, checkpoint saved, status CRITICAL. Test: Task 6 `test_fps_zero_is_critical`; Task 8 `test_env_crash_marks_critical`.
4. **GCS token expires / sync fails mid-run** → sync failures are logged and retried next interval; training never stops because of sync. Test: Task 9 `test_sync_failure_does_not_stop_training` (stubbed gsutil exits 1).
5. **Budget hit mid-update** → `BudgetCallback` stops at the next rollout boundary, final checkpoint + sync + `DONE` happen before pod removal. Test: Task 8 `test_budget_stop_writes_done`.
